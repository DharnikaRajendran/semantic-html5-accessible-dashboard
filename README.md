\# Semantic HTML5 \& Accessible Component Architecture



\## Project Overview

An accessible multi-page enterprise dashboard built using semantic HTML5 and CSS.



\## Features

\- Semantic HTML5 structure

\- Accessible navigation and page hierarchy

\- Employee data tables

\- Accessible registration form

\- Form validation

\- Accessible modal dialog

\- Responsive layout

\- Keyboard focus indicators



\## Technologies Used

\- HTML5

\- CSS3

\- JavaScript

\- W3C HTML Validator



\## Project Structure

\- index.html – Dashboard overview

\- users.html – Employee management

\- reports.html – Employee reports

\- style.css – Dashboard styling



\## Validation

All three HTML pages were checked using the W3C HTML Validator.

Result: Zero errors and warnings.
